    AI-Powered Financial Intelligence Lab

    Flagship Project · Analytics + AI

    A live financial analytics and AI research system combining portfolio tracking, market-data workflows, time-series analysis, visualization, and AI-generated commentary to study real-world market behavior.

    View Repository Explore Dashboard
    📦 Repository Structure

    This project currently lives in its own standalone public repository.

    DataEden / fin-tech-intelligence-lab-public

    The repository contains the public-facing documentation, notebooks, code, and project assets for the Financial Intelligence Lab.

    The repository serves as the project execution and documentation source while DataInsideData.com provides the presentation layer for browsing, explanation, and technical storytelling.

    🏗️ Documentation Architecture

    Project documentation is dynamically rendered from the repository README. DataInsideData.com retrieves the public README and converts the Markdown into HTML using the GitHub-hosted source and the site's README rendering workflow.

    This keeps the repository as the single source of truth while allowing the website to provide a more structured project presentation layer.

    The same project pipeline also produces daily and weekly AI-assisted research outputs using Python, Pandas, market data, portfolio data, and integrated AI workflows.

    As the publishing architecture evolves, this model can expand toward a more automated workflow connecting development, repository documentation, generated research outputs, and site presentation.

    System Architecture

    How the Financial Intelligence Lab Works

    The project combines data ingestion, processing, analytical workflows, visualization, AI-assisted interpretation, and application delivery as interconnected system layers.

    🔎 Data Sources

    Real-World Inputs

    The analytical pipeline integrates multiple sources:

    • Manual portfolio snapshots
    • Yahoo Finance market data via yfinance
    • Dividend tracking logs
    • Macro, market, and portfolio research notes

    These inputs are combined into analytical datasets used for time-series analysis, sector aggregation, visualization, and AI-assisted interpretation.

    Calendar model: The primary dataset currently follows equity trading days. Continuously traded assets such as crypto are therefore included only on applicable market-session dates. A separate 24/7 crypto time series may be added in a future iteration.

    ⚙️ Engineering

    Layered Data System

    • Raw Data → Portfolio Snapshots & Market Feeds
    • Processing → Merged Analytical Dataset
    • Analysis → EDA & Visualizations
    • AI Layer → Structured Insight Generation
    • Output → Reports, Dashboard & Site Integration

    The repository represents the execution layer, while DataInsideData.com provides the documentation and presentation layer.

    🤖 AI Insight Layer

    Structured Research Output

    The AI insight workflow generates structured analytical commentary including:

    • Daily portfolio commentary
    • Sector-level analysis
    • Market interpretation
    • Weekly summary reports

    The goal is to transform raw financial observations into readable, context-aware analytical outputs while retaining the underlying data workflow for review and continued experimentation.

    📊 Visual Analytics

    Analytical Views

    The project produces multiple views of portfolio and market behavior:

    • Portfolio value over time
    • Capital vs. market performance
    • Market gain tracking
    • Sector allocation trends
    • Position weights
    • Normalized asset performance
    • Dividend income tracking

    Visualization coverage will continue expanding as the analytical dataset and research layers mature.

    Live Application

    Financial Intelligence Dashboard

    The Streamlit application exposes the project pipeline through an interactive analytics interface.

    🖥️ Application Layer

    The dashboard surfaces portfolio metrics, asset performance, sector trends, and AI-generated research outputs produced by the Financial Intelligence Lab.

    The application represents the interactive layer of the project while the GitHub repository remains the source for code, datasets, notebooks, and technical documentation.

    Note: This dashboard is provided for educational, experimental, and portfolio-demonstration purposes only. It does not provide financial advice.
